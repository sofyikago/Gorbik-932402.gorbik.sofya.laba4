# Лабораторная работа №4

Основы JavaScript. Вариант 1 — «Студент-разработчик»: обработка баллов за лабораторные работы.

## Реализовано

* Файл `script.js` подключён к `index.html` через `<script src="script.js" defer>`
* Данные: массив из 7 баллов за лабораторные (от 0 до 100)
* Ввод: `prompt` для имени (если окно закрыто или поле пустое — подставляется «студент»)
* Функции: `findMax` (максимальный балл), `filterHighScores` (баллы ≥ 80), `calculateSum` (сумма баллов)
* Цикл `for` для подсчёта неудовлетворительных работ (балл < 50)
* Условные конструкции: проверка имени, сравнения в функциях, мотивационное сообщение
* Вывод `alert`: приветствие с именем и «У вас X отличных работ, максимальный балл – Y»
* Вывод `console.log`: средний балл и количество неудовлетворительных работ
* Дополнительно: при среднем балле ≥ 85 в консоль выводится мотивационное сообщение, при среднем ниже 85 — пояснение, что оно не выводится
* Режим `"use strict"`, вся логика (ввод, расчёты, вывод, проверка условия) вынесена в функции, в глобальной области — только константы и вызов `main()`

## Пример работы

Для данных `[95, 88, 100, 45, 92, 85, 90]`: отличных работ — 6, максимум — 100, средний балл — 85.00, неудовлетворительных — 1, мотивационное сообщение выводится.

Условие «средний ≥ 85» дополнительно проверено на трёх наборах: среднее 93.00 и 85.00 — сообщение выводится, среднее 70.83 — не выводится.
